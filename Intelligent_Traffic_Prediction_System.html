04 / Model strategy

Models considered

Candidate models are compared using the same target definition, chronological test period, and forecast horizon.

BASELINE 01

Historical Average

Reference forecast built from historical traffic patterns.

TIME SERIES 02

Learns nonlinear relationships from engineered features.

MACHINE LEARNING 04

XGBoost

Gradient-boosted trees for structured traffic data.

DEEP LEARNING 05

LSTM

Uses sequences to learn dependencies across time steps.

ADVANCED OPTION 06

DCRNN / Graph models

Can represent spatial road-network dependencies when topology is available.

05 / Evaluation framework

How forecasting quality is measured

Model selection should be based on measured results from the same held-out chronological test period.

MetricPurposePreferred
MAEAverage absolute errorLower
RMSEPenalizes larger errorsLower
MAPEPercentage-based errorLower*
R²Goodness of fitHigher

*MAPE can be unstable when actual values are zero or close to zero.

Data integrity matters

↗Split data chronologically into training, validation, and test periods.
↗Prevent future observations from leaking into preprocessing or training.
↗Apply the same feature-generation logic during training and inference.
↗Report each forecast horizon separately when multiple horizons are used.
